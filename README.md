# NAACL 2027 Anonymous Submission

This repository contains code and resources for the anonymous NAACL 2027 submission.

The reproducibility package is being organized. Documentation, environment specifications, preprocessing scripts, and evaluation commands will be added before submission.

## Repository structure

- `src/`: model and training code
- `scripts/`: preprocessing, inference, and evaluation entry points
- `configs/`: experiment configurations
- `docs/`: reproducibility documentation
- `results/`: aggregate validation results

## Anonymity

This repository intentionally omits author identities, private server paths, credentials, raw licensed data, and model checkpoints.
